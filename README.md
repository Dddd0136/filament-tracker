# Учёт филамента

Приложение для телефона, которое показывает остаток пластика на катушках 3D-принтера на Klipper. Расход списывается автоматически после каждой печати.

- **Приложение** (`docs/`) — PWA на GitHub Pages: ставится на Android как обычное приложение, тёмная тема, анимации.
- **Сервер** (`apps-script/`) — Google Apps Script поверх Google-таблицы. Данные хранятся в вашем Google Drive.
- **Принтер** (`printer/`) — скрипт для Klipper. В конце и при отмене печати он отправляет данные о печати; если интернета нет, отчёт ставится в очередь и уходит позже, повторы не задваиваются.

## Что сохраняется о каждой печати
- превью модели из слайсера (хранится в папке Google Drive «Филамент — превью моделей»);
- начало и конец, чистое время печати и общее с паузами, расчётное время слайсера;
- расход прутка в метрах и граммах — фактический и расчётный;
- стоимость (если у катушки указана цена);
- статус и процент выполнения для отменённых;
- высота слоя, высота модели, число слоёв, температуры, сопло, тип прутка, слайсер.

Вкладка «Статистика»: печати, часы, пластик и деньги за 7 дней, 30 дней и всё время; график расхода за 14 дней; расход по типам пластика.

Проверено на Elegoo Neptune 4 со стоковой прошивкой (Python 3.7).

## Установка

### 1. Google-таблица и Apps Script
1. Создайте Google-таблицу, затем откройте **Расширения → Apps Script**.
2. Вставьте `apps-script/Code.gs`. Создайте HTML-файл с именем `Index` и вставьте `apps-script/Index.html` (это запасная веб-страница; `docs/index.html` — тот же интерфейс для GitHub Pages).
3. Запустите функцию `setup` и разрешите доступ (таблица и Google Drive — для превью). В журнале появится `ТОКЕН: …`. После обновления кода запустите `setup` ещё раз — он добавит новые колонки, старые данные сохранятся.
4. **Начать развертывание → Новое развертывание → Веб-приложение**: выполнять от имени «меня», доступ «Все». Скопируйте адрес `…/exec`.

### 2. Приложение на телефоне
Откройте ссылку (подставьте свои значения):
```
https://<логин>.github.io/filament-tracker/#api=<адрес …/exec>&k=<токен>
```
Адрес и токен сохранятся только на этом телефоне. Затем в меню Chrome выберите **«Добавить на главный экран»** (или «Установить приложение»). Настройки можно поменять в любой момент кнопкой ⚙.

### 3. Принтер
1. Скопируйте `printer/spool_report.py` в `~/klipper_config/`, а `printer/spool_tracker.conf.example` — туда же под именем `spool_tracker.conf`, и впишите в него адрес и токен.
2. Добавьте в конфиг Klipper содержимое `printer/klipper_macros.cfg` и вставьте строки отправки в свои `PRINT_END` и `CANCEL_PRINT`.
3. Перезапустите Klipper и выполните `SPOOL_TEST`: во вкладке «История» появится тестовая запись.
4. Чтобы Moonraker мог извлекать превью и расчёт слайсера, у папки с файлами печати должен быть правильный владелец: `sudo chown -R mks:mks ~/gcode_files && sudo systemctl restart moonraker`.

Журнал отправки на принтере: `~/klipper_logs/spool_tracker.log`.

## Как пользоваться
- **«+»** — новая катушка: название, пластик, цвет, вес пластика.
- **Нажать на катушку → «Поставить в принтер»**: на неё будет списываться расход. Отмечайте при каждой смене прутка.
- **Взвесили катушку** — введите вес пластика без пустой катушки, и остаток пересчитается.
- **«Закончилась — в архив»** убирает пустую катушку из списка.

Учёт расчётный (по длине прутка), поэтому раз в пару месяцев стоит взвешивать катушки. При смене цвета посреди печати (`M600`) весь расход записывается на активную катушку.

Плотности пластиков (г/см³): PLA 1.24, PETG 1.27, ABS 1.04, ASA 1.07, TPU 1.21, PC 1.20, Nylon 1.14.
